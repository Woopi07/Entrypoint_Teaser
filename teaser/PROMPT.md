# BSAid — 30-Second Teaser · Director's Shot List

Paste this into any video editor brief or AI video generator. Timings match the rendered cuts in `out/`.

**Format:** 30 s · 30 fps · two deliverables: 16:9 (1920×1080) landscape and 9:16 (1080×1920) vertical for Reels/TikTok/Shorts. Keep all text inside the center 80 % safe area so one edit works for both crops.
**Look:** clean, academic, and fun. Navy `#1B2A5C` + gold `#F5B82E` brand colors, cream ledger paper, flat illustrated characters with soft shading. Typeface: a geometric sans (Inter / Inter Display), monospace for peso amounts.
**Logline (on screen exactly as written):** *"Every transaction tells a story. Will you make the right entry?"*

- **Character art:** the GDD (v1) only has reference images that aren't original art. The teaser uses original placeholder sprites in the same color palettes. Swap in the team's final Faraday and Farahnaz art when it's ready.
- **Gameplay footage:** the UI is rebuilt from the GDD's *GUI Layout: Accounting Challenge Screen*. If you have screen recordings of the live Vercel build, cut them in over 0:06–0:11.6 at the same timings.
- **Official audio:** the GDD lists YouTube references for the achievement sound, the wrong-answer BGM and the main-menu/gameplay BGM. The rendered teaser uses an original synthesized score that hits the same cues (achievement at 0:11, fanfare at 0:22). Replace it with licensed versions of those tracks if you have the rights.
- **Rank table shown (from the GDD):** S = 0 mistakes = 100 pts · A = 1–2 = 80 · B = 3–5 = 60 · C = 5–7 = 40 · D = 7+ = 20.
